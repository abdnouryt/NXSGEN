## 🌋 What is NXSGEN?

**NXSGEN** (pronounced *"Next Gen"*) is an advanced **cinematic prompt engineering system** that transforms any reference image into a hyper-detailed, structured JSON prompt capable of producing **photorealistic, cinematic-quality images** on any AI image generator.

> **The Problem:** AI image generators are literal-minded. Vague prompts produce vague results.
>
> **The Solution:** NXSGEN analyzes images through **65+ professional layers** — the same way a master cinematographer, production designer, and colorist would — and outputs a comprehensive prompt that leaves **nothing to chance**.

<br/>

## 🚀 Quick Start

### Step 1: Copy the System Prompt
Copy the entire NXSGEN system prompt from the /system-prompt directory




### Step 2: Start a New AI Conversation
Paste the system prompt into Claude, ChatGPT, or any LLM




### Step 3: Send a Reference Image
Upload any image from Pinterest, Instagram, or your camera roll




### Step 4: Receive Your JSON
NXSGEN analyzes 65 layers and outputs a complete JSON prompt




### Step 5: Generate
Copy the main_prompt (or entire JSON) and paste into your AI image generator

### 10 Core Principles

| # | Principle | Explanation |
|:-:|:----------|:------------|
| 1 | **AI Is Literal** | Describe EVERYTHING as if explaining to someone who has never seen anything |
| 2 | **Redundancy Is Power** | Say critical things 3 ways: technical term + plain description + emotional effect |
| 3 | **Invisible Details Matter** | Describe what you don't consciously notice but your brain processes |
| 4 | **Anti-Failure Engineering** | For every known AI weakness, include explicit corrective instructions |
| 5 | **Presets Fill Gaps** | When analysis is incomplete, matched presets provide quality defaults |
| 6 | **One JSON Rules All** | Interconnected data produces dramatically better results than flat text |
| 7 | **Every Pixel Has Purpose** | No random element. Every color, shadow, and wrinkle serves the story |
| 8 | **Over-Describe Always** | 400 detailed words always beat 50 vague ones |
| 9 | **Real References Only** | Real cameras, real lenses, real film stocks. AI responds to specificity |
| 10 | **Negatives Are Half The Battle** | Telling AI what NOT to do is as important as what to do |
